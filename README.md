# Calculadora Angular

Proyecto basado en el ejercicio de clase de Angular.

## Funciones
- Ingresar dos números.
- Seleccionar operador: suma, resta, multiplicación o división.
- Realizar la operación.
- Mostrar el resultado.
- Guardar las operaciones en un historial.
- Validar campos vacíos y división entre cero.
- Botón para limpiar la calculadora.

## Cómo ejecutarlo

Necesitas Node.js instalado.

1. Abre esta carpeta en Visual Studio Code.
2. Abre la terminal.
3. Ejecuta:

```bash
npm install
```

4. Luego:

```bash
npm start
```

5. Abre en el navegador:

http://localhost:4200

## Estructura principal

- `src/app/app.component.ts` → lógica.
- `src/app/app.component.html` → interfaz.
- `src/app/app.component.css` → estilos.
- `src/styles.css` → estilos generales.
